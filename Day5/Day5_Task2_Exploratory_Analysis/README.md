# Day 5 – Task 2: Exploratory Analysis

## Files
- `Employee_Analysis.ipynb` — notebook covering every assignment requirement.
- `employee_data.csv` — small practice employee dataset.
- `department_budget.csv` — second table for the `pd.merge()` exercise.
- `department_analysis_with_budget.csv` — generated when the final notebook cell runs.

## Run in VS Code
1. Extract the ZIP and open the `Day5/Employee_Data_Analysis` folder in VS Code.
2. Install dependencies in your active virtual environment:
   `python -m pip install pandas numpy jupyter`
3. Open `Employee_Analysis.ipynb`.
4. Select your `.venv` Python kernel if prompted.
5. Run cells from top to bottom using **Run All**.

The notebook calculates numeric answers from the included practice data. If you have a dataset supplied by your trainer, use that file instead and update the column names in the notebook if they differ.
