# Employee Data Analysis Project

## 1. Project Overview

This project focuses on analyzing employee data to understand employee attrition and identify the factors that influence employee retention.

## 2. Dataset Details

- **Dataset Name:** IBM HR Analytics Employee Attrition
- **Total Records:** 1470
- **Total Columns:** 35
- **File Format:** CSV
- **Source:** Kaggle

## 3. Tools and Technologies

- Python
- Pandas
- Jupyter Notebook
- VS Code
- Git and GitHub

## 4. Initial Data Analysis

The following operations are performed:

1. Load the employee dataset using Pandas.
2. Check dataset shape using `shape`.
3. Check column details using `info()`.
4. Generate statistical summary using `describe()`.
5. Identify missing values using `isna().sum()`.
6. Identify duplicate records using `duplicated().sum()`.

## 5. Business Questions

1. Which department has the highest employee attrition?
2. Which job roles have the highest employee turnover?
3. Does overtime affect employee attrition?
4. Does job satisfaction influence employee attrition?
5. Is there a relationship between monthly income and employee attrition?
